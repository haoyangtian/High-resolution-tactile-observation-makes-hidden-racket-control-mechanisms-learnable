Posture reconstruction

Pose regression and selected planar kinematic and geometric utilities; not a complete physical reconstruction pipeline.

Install from the repository root with: python -m pip install .
Import namespace: tactile_components.posture
Modules: pose_model, hand_kinematics, grip_geometry

This directory contains usable components, not an end-to-end reproduction workflow.
Original numeric constants and constructor defaults are available in the source.
Library defaults are not asserted to be the frozen configuration of every manuscript experiment.
