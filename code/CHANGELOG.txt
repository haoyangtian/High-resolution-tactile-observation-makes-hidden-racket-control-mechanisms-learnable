Component release 0.3.0 (2026-10-26)

- Removed the standalone latent autoencoder/diffusion prototype. Current motion
  guidance uses RewardModel and the conditional Gaussian ImuPriorModel instead.
- Removed the standalone binary SVM helper from the historical zero-shot
  eta/Koopman-feature analysis; retained multimodal proficiency feedback.
- Removed the unused _modularity_from_edges helper, whose calculation did not
  implement standard modularity. Neither partition backend called it; their
  code and backend-provided scores are unchanged.
- Removed the empty readme placeholder and the three synthetic tests specific
  to the removed models. Retained all 20 tests of the remaining components.
- Updated package documentation, the source manifest and validation record.
  Study data and analysis results were not modified.

The removed modules were not dependencies of the retained components. Legacy
branches within the control model remain intact for state-dictionary compatibility.
The 0.2.0 source is retained in Git history at commit
2eb4dda3d1acabb02e2caf1ad5b2900c8d517535.

Component release 0.2.0

This replaces the earlier non-executable redacted excerpt package.
- Restored original numeric constants, string values and constructor defaults.
- Removed unconditional import failures and all undefined redaction markers.
- Included explicit dependencies and standard package installation metadata.
- Renamed partial hand helper collection to PlanarHandKinematics.
- Added software tests using synthetic inputs; no study results are asserted.
- Added graph input validation and support for non-contiguous tensors.
- Corrected singleton graph handling without changing normal graph behavior.
- Made graph partition backend selection explicit, with no silent fallback.
- Made local forest configuration explicit instead of reading mutable globals.
- Corrected the historical window-normalized temporal block's misleading causal
  name without changing its numerical implementation. Current encode uses a
  separate frame-wise path; future-frame independence is tested on that path.

Statistical inference, manuscript metric aggregation, plotting, participant
records, fitted weights and full experiment orchestration remain outside scope.
The release does not establish reproducibility of the manuscript's main results.
SOURCE_MANIFEST.json describes the exact per-module adaptations.
